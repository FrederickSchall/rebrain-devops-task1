## О проекте

Nginx — это высокопроизводительный веб-сервер, который также может использоваться в качестве обратного прокси-сервера, балансировщика нагрузки и HTTP-кэша.

Основная задача данного проекта — предоставить отправную точку для работы с конфигурацией Nginx.

> Хорошая конфигурация веб-сервера — основа стабильной и предсказуемой работы веб-приложения.

## Возможности

На текущем этапе репозиторий содержит:

- Базовый конфигурационный файл `nginx.conf`.
- Возможность адаптации параметров веб-сервера под конкретную инфраструктуру.
- Возможность проверки конфигурации перед применением.
- Контроль изменений с помощью Git.

Для работы с проектом потребуются:

## Установка и использование

### 1. Клонирование репозитория

```bash
git clone https://gitlab.rebrainme.study/streams/devops/users/a.bogoderov.work-6069/rebrain-devops-task1.git
```

### 2. Переход в каталог проекта

```bash
cd rebrain-devops-task1
```

### 3. Просмотр конфигурации

```bash
cat nginx.conf
```

### 4. Проверка конфигурации

Если Nginx установлен, можно проверить конфигурационный файл командой:

```bash
sudo nginx -t -c "$(pwd)/nginx.conf"
```

Успешная проверка обычно сопровождается сообщением:

```text
syntax is ok
test is successful
```

**Важно:** перед использованием конфигурации в рабочей среде необходимо проверить пути к подключаемым файлам и соответствие параметров требованиям конкретного сервера.
